# استوديو الانحناء — Curve Studio 3D 🌀

<div dir="rtl">

**استوديو 3D يعمل في المتصفح مباشرة (بدون خادم):** اعرض صورتك كبطاقة/شاشة منحنية تشبه الهاتف — دون إطار هاتف — قابلة للدوران 360 درجة، مع نصوص عربية وإنجليزية بعشرات الخطوط، وطبقات كاملة، وتحكم شامل من الهاتف والحاسوب.

## ✨ المزايا

- 🖼️ **صورتك كبطاقة منحنية**: أضف صورتك فتظهر كسطح ثلاثي الأبعاد بحواف مستديرة كالهاتف، مع انحناءات حقيقية (قوس، لفة نصف أسطوانية، موجة، التواء، قبة) — دون أي إطار جهاز.
- 🔄 **دوران 360°**: اسحب الخلفية للدوران الحر في كل الاتجاهات، مع وضع عرض مخصص ودوران تلقائي.
- ✍️ **نصوص بخطوط كثيرة**: أكثر من 50 خطاً عربياً وإنجليزياً (Cairo، Amiri、Tajawal、Reem Kufi、Rakkas… وInter、Poppins、Bebas…) مع حجم، وزن، ميل، تباعد، حدود، لون، خلفية كبسولة، ومحاذاة RTL/LTR تلقائية.
- 🔀 **تحريك وإمالة وتحجيم كامل**: سحب بالفأرة/اللمس، إمالة X/Y/Z، دوران Z، تحجيم، شفافية — أو بالكيبورد بدقة.
- ⬒ **تحكم بالحواف**: استدارة الحواف، سماكة الإطار ولونه، وظل اختياري.
- 🎨 **خلفية بيئة العمل**: لون (أبيض افتراضياً)، تدرّج بشريحة زاوية، أو شفافة للتصدير PNG.
- 📚 **شريط عمل سفلي بالطبقات**: شرائح قابلة للسحب لإعادة الترتيب (نص فوق صورة أو العكس)، تحديد بالنقر على العنصر أو شريطه، إظهار/إخفاء، قفل، حذف، وإعادة تسمية.
- 🗂️ **بيئات عمل متعددة**: إنشاء/إعادة تسمية/حذف، مع اختيار الحجم (مربع، ستوري، هاتف، غلاف أو مخصص) وحفظ تلقائي في المتصفح.
- 💾 **حفظ الصورة PNG** بدقة بيئة العمل كاملة + نسخة احتياطية JSON للمشروع كله.
- ⬛⬜ **واجهة بيضاء/سوداء بسيطة** مع وضع ليلي، ومتوافقة مع الهاتف والحاسوب والماوس والكيبورد.
- ↩️ تراجع/إعادة (Ctrl+Z / Ctrl+Y)، تكرار، لصق صور من الحافظة (Ctrl+V)، سحب وإفلات الملفات.

## 🎮 التحكم

| الفأرة / اللمس | العمل |
| --- | --- |
| سحب عنصر | تحريكه داخل المشهد |
| سحب الخلفية | دوران الكاميرا 360° |
| العجلة | تقريب/تبعيد (Ctrl+عجلة: تحجيم المحدد) |
| إصبعان على العنصر | تكبير + تدوير |
| ضغطة على العنصر أو شريطه | تحديده وإظهار خصائصه |

| الاختصار | العمل |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z` | تراجع / إعادة |
| `Ctrl+D` / `Ctrl+S` | تكرار / حفظ الصورة |
| `T` / `I` | نص جديد / صورة جديدة |
| الأسهم | تحريك دقيق (Shift أسرع) |
| `Q` `E` / `W` `S` / `A` `D` | دوران Z / إمالة X / إمالة Y |
| `+` `-` | تحجيم · `R` تصفير الميل · `0` ملاءمة العرض |
| `M` / `G` / `H` / `Esc` | وضع التحرير-العرض / الشبكة / المساعدة / إلغاء التحديد |

## 🚀 النشر على Vercel

1. اعمل Fork أو استورد هذا المستودع في [vercel.com/new](https://vercel.com/new).
2. إعدادات الاستيراد: **Framework Preset: Other** — اترك **Build Command** و**Output Directory** فارغين (الموقع ثابت وجاهز في جذر المستودع).
3. اضغط Deploy — وستحصل على رابط مباشر خلال ثوانٍ.

> الملف `js/app.bundle.js` مُبنى مسبقاً، فلا حاجة لأي خطوة بناء عند النشر. إن أردت البناء بنفسك: `npm install && npm run build`.

### التشغيل محلياً

```bash
git clone https://github.com/doujohn097-code/curve-studio.git
cd curve-studio
npx serve .        # أو: python3 -m http.server 8000
```

## 🛠️ التقنيات

- [Three.js](https://threejs.org/) (WebGL) — أسطح منحنية بتعديل رؤوس هندسة البطاقة في الوقت الفعلي.
- Canvas 2D لتوليد خامات الصور والنصوص العربية (تشكيل واتجاه صحيحان).
- JavaScript أصلي + esbuild، بلا أي اعتماد على خادم — كل شيء يعمل في المتصفح.
- Google Fonts لخطوط الويب.

### بنية المشروع

```
├── index.html          # الصفحة (خطوط + هيكل الواجهة)
├── css/style.css       # التنسيق الأحادي (أبيض/أسود + وضع ليلي + استجابة)
├── js/app.bundle.js    # الحزمة المبنية (Three.js + التطبيق)
├── src/                # المصدر
│   ├── main.js         # الإقلاع، الإيماءات، الكيبورد، الحفظ التلقائي
│   ├── scene.js        # مشهد Three.js والتصدير PNG
│   ├── geometry.js     # توليد الانحناءات (قوس/لفة/موجة/التواء)
│   ├── textures.js     # خامات الصور والنصوص
│   ├── state.js        # الحالة، الطبقات، التراجع، التخزين المحلي
│   ├── panel.js        # لوحة الخصائص
│   ├── bar.js          # شريط الطبقات السفلي
│   ├── ui.js           # الترويسة والنوافذ والثيم
│   └── icons.js        # أيقونات SVG
├── tools/smoke.mjs     # اختبار آلي (Playwright)
└── docs/               # لقطات الشاشة
```
